# 内容整理与解题

## 课程材料

先建立本次材料的页码/章节清单，区分行政信息、概念、公式理论、例题、练习及答案。可以合并重复幻灯片，但不能因只提取到正文就漏掉图中条件、表格、页脚题目或附录答案。“全部题型”指当前材料范围，不扩展成整个学科大全；扩充内容明确标成补充。

每章的推荐内容顺序：

1. 学习范围与知识地图：本章主题、先修知识、与相邻章节联系。
2. 核心概念与理论：准确含义、相近概念区别、适用条件及反例。英文材料保留必要原文并提供中文解释，关键术语做中英对照；中文材料不附例行英文译文和词表。
3. 公式、规则或理论框架：符号、单位/定义域、假设、适用边界、必要推导；无公式的学科改为理论/方法依据，不能硬凑公式栏目。
4. 题型与解法地图：识别线索 → 选用方法的理由 → 解题步骤 → 检查方法 → 关联例题。文字题可归纳为名词解释、比较、分析、论证等，程序题可按算法/数据结构归纳。
5. 例题和材料内练习：按下方对应语言的作业顺序展开。完整保留可定位的题号和子问；有原答案保留对照。
6. 考点、易错点与复习：标明考点依据，提供自测提示和答案入口；知识量小的页面不必堆砌空栏目。

英文课程中的概念解释默认用中文，关键术语保留英文以便对照授课和考试。不是逐句翻译每张幻灯片；对需解答的英文题干提供完整中文翻译。若用户另行要求全文翻译，才扩展范围。

## 作业：英文分支的固定顺序

每题使用稳定标识，如 `ch04-p56`；不同教材/版本的同号题要区分来源。

1. **原题**：准确转录英文题干、条件、子问、单位、图注及给定答案；附原图/来源页定位。无法辨认的字符显式标为未确认，不擅自改写原文。
2. **中文翻译**：对应题干所有子问；尤其忠实于否定、比较、方向、初始/边界条件以及“证明/计算/讨论”等任务动词。不要把假设或解释偷加进翻译。
3. **中英专业名词对照**：只选影响本题理解的词语，给出在本题中的准确含义；避免全词汇翻译表。
4. **英文解题过程**：用可提交作业的清楚英语陈述变量/依据、推导或论证、必要代入、分问结论与单位。不能只有公式或最终数字。用户需要特定格式时遵从。
5. **中文解析**：解释“为什么这样做”“如何从题干认出该题型”“关键一步的逻辑”，不要只重复英文过程的逐句翻译；含可识别的最终答案，与英文结果一致。
6. **公式定理/理论依据**：列本题实际使用的定义、理论、算法或论证框架，说明适用条件和符号；必要时链接课程知识页。
7. **易错点分析**：具体到本题的易错条件、错误做法为何错和检查方式，避免泛泛的“认真审题”。

多题可在末尾追加答案汇总，不打乱每题上述顺序；例题较短时保持紧凑。

## 作业：中文分支的固定顺序

1. **原题**：中文原文及必要的英文术语、代码或符号原样保留，附来源。
2. **中文解题过程与解析**：完整步骤/论证、方法选择、全部子问结论及检查。可以在此栏内分“过程”“解析”，不增加英文版过程。
3. **公式定理/理论依据**：使用的规则和条件；无公式则用学科理论或方法。
4. **易错点分析**：具体的误区、检查办法；答案汇总按需添加。

不生成“中文翻译（略）”“英文过程（不适用）”等空位，也不因为出现 GDP、DNA、Python、向量 i/j 就切换英文分支。对于已经提供中文的双语题，保留必要英文原文即可。

## 答案与证据

- 给定答案与独立推导分别标注。按给定答案补足过程，但先核对题干、版本、单位与符号约定；不为凑答案添加不存在的条件。若发现矛盾，保留原答案并展示核验结果。
- 明确区分原文条件、建模假设、推导结论、补充知识和不确定转录。存在多种合理解释时，标出差异并给条件解；缺关键数据不能给伪精确数字。
- 考点必须有来源类型：明确考核要求/真题证据/作业出现/推测。没有大纲或真题时，输出“复习重点/可能考查方式”，不宣称考试概率。
- 用户补充更清晰题图或标准答案后，应更新对应原题和解法，注明有实质影响的修订并同步汇总，保留可追溯来源。

## 学科适配与验证

| 类型 | 内容适配 | 有意义的验证 |
| --- | --- | --- |
| 数学、物理、工程 | 条件、符号、坐标/正方向、定理与推导 | 代回、量纲、边界/极限、第二方法；避免把某题的无摩擦假设全局化 |
| 化学、生命科学、医学 | 反应/机制、结构与功能、条件和例外 | 守恒、计量、命名、机制和课程来源；教学案例不冒充临床建议 |
| 计算机、编程 | 算法思路、复杂度、代码与边界输入 | 现有环境中运行代表样例；若未执行，清楚标记为推演结果 |
| 经管、统计、社会科学 | 模型假设、变量含义、解释与比较 | 计算复核、样本/总体区分、因果/相关区分，注明材料证据 |
| 历史、文学、法学等 | 概念、时间/背景、比较、论点—证据—分析 | 时间线、引文与出处、论据能否支持结论；开放题给参考论证及可接受替代观点 |
| 外语与语言课程 | 词义、语法、翻译/写作任务、评价标准 | 语境、搭配、语法与题目要求；即使整体为中文分支，也保留题目必须的外语答案 |

语言分支针对学习资料的组织语言，不取消课程任务本身要求的语言或代码，例如中文题干要求“用英语写一封信”，仍须完成英文信件，但不附加整套双语解题包装。

## 期末整合与持续复习

平时更新时把新知识点、题型、理论与习题互相链接。用户要求期末复习时再按当前已整理范围生成整合页：知识地图、公式/理论速查、题型方法、典型题、常见误区及未解决清单。存在个人作答记录时才生成个人错题清单。

自测应让用户能先看问题再展开答案；按知识点选择代表题，不重复堆叠所有原题。没有用户表现记录就不推断掌握程度，不擅自创建提醒或复习日程。来源不足或章节尚未处理时在复习页注明覆盖边界。
