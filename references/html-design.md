# 固定 HTML 架构与视觉规范（版本 1）

## 默认构建，不是可选建议

每次运行 study-flow，除非用户明确说“不用 HTML / 不用可视化 / 只在聊天回答”等，必须把本次课程总结或作业解答构建成实际 HTML，并更新学习库入口。只有作业就构建作业页，只有课程材料就构建总结页；不能为凑模板编写未提供的学习内容。所有页面中的公式都遵循 `formula-rendering.md`。

现成资源：

- `scripts/build_page.py`：从 JSON 内容规格生成固定总目录、章节或作业 HTML，并复制离线资源。
- `scripts/build_search_index.py`：从实际 HTML 正文重建跨页离线搜索索引；页面构建后自动执行，也可独立用于更新既有学习库。
- `assets/study-ui.css`：唯一基础视觉样式，不要每次重新设计。
- `assets/study-ui.js`：本地公式渲染、目录展开、当前章节提示、自测展开及打印处理。
- `assets/vendor/katex/`：固定版本 KaTeX 0.16.22、化学公式扩展、字体与许可证。不在每次课程运行时下载或安装依赖。
- `assets/examples/`：三种架构的内容规格，兼作可构建的设计样例；真实资产需替换为本次已核实课程内容，不能把演示内容计入课程覆盖。

## 页面骨架

所有页面：无侧栏遮挡的跳转正文链接 → 深蓝页头（课程、页名、范围/语言标签）→ 桌面左侧目录 + 右侧正文 → 底部返回总目录与来源提示。进入章节、题目等具体分块仍保留左侧目录，可快速跳至分块内的小节/原题/解题过程/易错点等。桌面“关闭”按钮收起整个侧栏，正文扩展；页面左上角保留“打开目录”入口，可重新打开。手机改为正文上方的可展开目录，也支持关闭和重新打开；不能关闭后找不到恢复入口。不依赖固定底栏或复杂动画。

| 页面类型 | 固定正文架构 | 呈现 |
| --- | --- | --- |
| 总目录 `index` | 学习总览 → 章节知识 → 作业题库 → 知识点与题型索引 → 期末复习入口 → 来源与核验记录 | 章节/作业用链接卡片，索引用表格或分组列表，未整理范围明确列出 |
| 总结 `chapter` | 本章地图 → 核心概念 → 公式/理论与条件 → 题型与解法 → 例题解析 → 考点与依据 → 易错点 → 自测与复习 → 来源与核验记录 | 概念卡、渲染公式、方法步骤、例题完整流程、带依据的考点标签、可展开答案 |
| 作业 `homework` | 本次作业范围 → 逐题卡片 → 答案速查 → 来源与核验记录 | 每题有稳定题号和语言标签，正文按既定语言流程，结论独立绿色答案区，原图可查看 |

英文逐题栏目：原题 → 中文翻译 → 双语术语 → English Solution → 中文解析 → 公式/理论依据 → 易错点。中文逐题栏目：原题 → 中文解题过程与解析 → 公式/理论依据 → 易错点。总结中的例题也按同一语言流程呈现。

正文按内容填充，不能伪造题目、例题或真题频次。材料没有某类内容时简洁说明“本次材料未提供”，或引用已有对应页面；不是省略整个交付。用户明确要求省略栏目时才在规格中记录省略原因。

## 固定 UI

- 基调：深蓝 `#142b4b` 页头、灰白 `#f3f5f9` 背景、白色内容卡、靛蓝 `#355bc2` 链接。正文深色，避免用纯颜色表达唯一含义。
- 语义：蓝色提示框用于方法/条件，绿色答案框用于结论，琥珀色警示框用于误区/不确定条件；明确写出标题。不要给每科随意换一套皮肤。
- 字体：中文使用系统雅黑/苹方，英文使用 Segoe UI，公式使用本地数学字体；正文 16px、行高 1.85。字号层级由 CSS 固定。
- 桌面最大宽 1320px，220px 侧栏，正文自适应；卡片圆角 14px、留白 26–30px。850px 以下单列，手机边距 18px。
- 表格用 `.table-scroll` 容器；公式块用 `.math-display`；仅容器横向滚动，禁止把整页撑宽或通过 `overflow-x:hidden` 隐藏丢失内容。超长行内公式改为独立公式块。
- 每道题使用 `.problem`；分段使用 `.problem-part` 和连续的步骤标签。答案保持可见，不默认折叠解题过程；只折叠自测答案或次要补充。
- 每题分段固定 ID 为 `<题目ID>-<分段键>`，如 `ch04-p56-analysis_zh`，二级目录直达该分段；总结的小标题优先使用作者指定的语义化 ID，未提供时 JS 自动生成分块内 ID 并加入二级导航。链接与侧栏在进入分块时持续可用。
- 自测用 `<details><summary>问题</summary>答案...</details>`。页面提供“展开/收起自测”“打印/保存 PDF”按钮；打印前展开答案，隐藏导航与交互，白底深字。不能把按钮本身当作已经导出 PDF。
- 图片保留宽高比，提供说明和来源；SVG 辅助图明确标注“重绘”。用静态图解解释关系，无必要不加入交互模拟器。

## 关键词搜索（默认构建）

参考概率论项目“全站搜索 + 本页筛选”的使用方式：所有新页面正文顶部放置搜索框、全学习库/本页范围选择和清空按钮。支持中文、英文、大小写不敏感匹配、题号和多个空格分隔关键词（同时满足）；结果展示所属章节、标题、正文摘要、匹配高亮和精确锚点，显示结果数量，无结果时明确提示，可继续加载更多结果。

本页查找通过结果列表直达分块，不隐藏原正文，避免搜索、目录跳转和原图返回互相干扰。高亮仅作用于结果标题/摘要的文本节点，不能直接替换正文 HTML 或破坏 KaTeX。摘要用“[公式]”标明原文的公式位置，不输出裸 TeX；公式源码保留为后台匹配关键词，完整渲染式通过结果链接查看。点击隐藏自测内部的锚点时应展开父级折叠块。

`build_page.py` 构建后自动从学习库根目录实际存在的 HTML 正文重建 `assets/study-flow/v1/search-index.js`，可纳入有正文的旧页面；原图、搜索 UI 不作为学习内容索引。索引通过本地 `<script>` 加载，在 `file://` 打开也能工作，无 fetch、后台或在线搜索依赖。检索图片中的文字依赖已核实的题干转录，不声称自动搜索未 OCR 的图片。

增量更新保留其他页面的搜索条目，修改页内容后旧条目应被替换，不累积重复版本。沿用其他构建器的库也要更新其等价索引；不能只改页面却漏掉搜索。可单独运行 `python <技能目录>/scripts/build_search_index.py <课程库目录>`。

## 作业原图直达与原位返回（有原图则必做）

作业规格提供 `source_images` 列表，每张图有 `id`、库内相对 `src`、说明 `label`。图片先归档到 `sources/`；跨页题干、作业清单及同一题多张图均保留，标清对应题号和页码。示例 `homework.json` 对应的演示图为 `assets/examples/homework-source.svg`，构建设计样例时复制到样例库的 `sources/demo-homework.svg`，真实任务则使用用户提供的原图。

作业页左侧固定“作业原图”快捷区，提供全部原图及逐图链接；正文设 `original-images` 原图区。点击直达时记录原滚动坐标、URL 锚点、侧栏内部滚动与手机目录展开状态。原图区顶部和各图下方提供返回按钮，一键恢复刚才阅读的位置；不是回页首、不是新开无返回的裸图片页、也不是只回该题标题。连续查看多张原图仍保留最初阅读位置；返回后再次跳图应重新记录。

桌面/手机均支持；关闭侧栏后仍可通过“打开目录”访问原图入口。手机另有持续可见的“查看作业原图”快捷入口，避免先滚回顶部才能找原图而丢失阅读位置。原图清晰且保持比例，打印时隐藏返回按钮。直接通过外部链接打开原图区、没有返回记录时，不展示失效返回按钮。纯文字作业确无图片时使用 `source_images_note` 解释材料形态，不生成空画廊或假图片。

## 生成方式

先读取对应 `assets/examples/*.json` 的字段，再编写本次规格。标题、课程、标签等普通字段由构建器转义；`sections`、`parts`、`answer_html`、`sources_html` 是助手撰写的可信 HTML 片段，源材料中的 `<`、`&` 等必须转义，禁止直接插入来源中的脚本或事件处理器。

```text
python <技能目录>/scripts/build_page.py <本次内容.json> --library <课程库目录> --page <章节或作业.html>
python <技能目录>/scripts/check_library.py <课程库目录>
```

脚本路径和课程路径使用绝对路径并按当前 shell 引号规则传递，Windows 可用 PowerShell 7；WSL 则把两端路径都转为 Linux 路径。JSON 为 UTF-8，不把带中文脚本从旧 PowerShell 管道送入 WSL。

- `kind` 为 `index`/`chapter`/`homework`，对应固定栏目。
- `sections` 使用样例中的固定键；每道作业 `parts` 按 `language: en/zh` 选择，中文题不能携带英文分支字段。
- `answer_html` 是本题明确结论，`sources_html` 记录来源、页码及实际核验结果。不要自动写“全部检查通过”。
- 有原图的作业必须填 `source_images`；无图时填 `source_images_note`。原图缺失不能用说明字段掩盖，仍须列入待补充项。
- 原题/知识点引用的公式标记见公式规范。示例中的 `derived` 表示演示推导，不是原始课件来源。
- 默认拒绝覆写已有页。确需更新时先读原页，保留旧内容和锚点后准备完整规格，再用 `--replace`。保留本次规格作为可重建资产，放在课程库 `page-specs/` 或既有等价位置。
- 新学习库必须构建 `index.html`。已有学习库可只增补入口，不强制整体迁移。不要用不完整规格覆写已有总目录。
- 明确省略需 `omit_sections` 和 `user_omission_note`；作业中按题记录。正常运行不能自填“用户要求省略”来绕过默认构建。

## 完成条件

除内容核对外，检查桌面（约 1440px）和手机（390px）截图、打印布局、目录链接、离线字体和全部公式。新页面应有 `data-study-kind` 和 `data-template-version="1"`。示例成功不能替代对真实课程材料的核对。环境确实缺少渲染工具时照样生成资产，明确列出未核验项；公式未渲染、未确认或使用猜补的页面不能标为完整完成。
