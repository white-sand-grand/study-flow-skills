# 原式忠实渲染与核验

## “照原样”的含义

所有出现的数学/化学公式，包含原题、课程知识、解题过程、答案汇总和表格中的公式，都必须以正确排版的表达式展示。原材料中的公式保留符号、希腊字母、大小写、向量箭头/粗体、下标上标、分式层次、积分/求和上下限、微分符号、括号、矩阵/分段结构、多行对齐、单位和原编号。排版字体可因浏览器不同略有区别，结构与含义不能改变；需要逐像素复刻或无法可靠重建时使用清晰原公式裁图。

不能以等价但不同的改写代替“原式”；例如不能把原式分式化成斜杠串、把向量换成未声明的标量，或为简洁省去积分限。需要推导、统一记号或纠错时，先展示原式，另标“推导/等价形式/勘误”，保留来源依据。

严禁把公式放进普通 `code`/`pre` 当作排版结果、用 Unicode 拼凑复杂结构、显示未处理的 `$...$`/`\(...\)` 或裸 LaTeX。原文代码中的表达式仍按代码保留；其数学解释另行渲染。不需要在无公式的学科页面硬加公式。

## 标准标记与本地渲染

构建器打包的 KaTeX 0.16.22 支持常见 TeX 和 `mhchem` 化学扩展。页面 JS 按 `data-tex` 属性处理，不对整页盲目扫描美元符号；由此不会把金额、代码误当公式。

```html
<span class="math-inline" data-tex="v_0" data-formula-id="ch02-v0" data-source="notes.pdf#page=8"></span>
<div class="math-display"
     data-tex="\vec{a}=\frac{d\vec{v}}{dt}=\frac{d^2\vec{r}}{dt^2}"
     data-formula-id="ch02-acceleration"
     data-source="notes.pdf#page=8"></div>
```

这里展示的是最终 HTML 标记，因此 `data-tex` 中每个 TeX 命令使用单个反斜杠。写入 JSON 规格时按 JSON 规则把反斜杠转义成两个，HTML 属性中的 `&`、双引号及 `<` 按 HTML 规则转义。不得额外加 `$` 或 `\[` 定界符。多行 TeX 用 `aligned`，矩阵用 `bmatrix` 等环境；有原编号时在旁保留或使用支持的编号方式，不擅自重新编号。

每个公式元素有稳定 `data-formula-id` 和可定位的 `data-source`：源公式指向课件/原图页码；自主推导标 `derived:<关联题号/原公式ID>`；题干看不清标为未确认，不能作为已核实原式。不同位置重复展示同一个公式允许复用同一公式 ID。

运行后检查：所有 `[data-tex]` 都是 `data-math-state="rendered"`，且 `document.documentElement.dataset.mathReady === "true"`、`mathErrors === "0"`。自动检查只能证明解析成功，不能证明 OCR 或公式转录忠实，仍需对照源图。

## 不支持或源文不清时

1. 先确认是 TeX 转录错误、KaTeX 不支持的命令，还是原图本就不清晰。不能让 `throwOnError:false` 掩盖问题，不能通过删掉未知记号使渲染通过。
2. 对源公式可直接从用户提供的原图/PDF 裁出清晰公式区域，保存到库内 `sources/formulas/`；留足上下限、编号和箭头的边界。用下方标记展示，不拉伸、不截断。
3. 对自行推导的新公式或需要可选择文字的复杂式，可用可用的 MathJax/LaTeX 等工具渲染为本地 SVG/清晰图片，保留 TeX 和来源。实际调用编译工具时读取当前对应技能（如 `latex-compile`），不要假设某环境一定装有 TeX。
4. 裁图不能恢复已经缺失的公式。仍无法辨认的符号或参数明确向用户索取清晰材料，资产状态为待补充；不猜补、不声称原样完成。

```html
<figure>
  <img class="formula-image" src="sources/formulas/ch02-eq3.png"
       alt="第2章第3式，原图公式"
       data-formula-id="ch02-eq3" data-source="notes.pdf#page=8">
  <figcaption>原式裁图 · 课件第8页，第3式。保留原符号与编号。</figcaption>
</figure>
```

## 必做验证

- 逐式对照源材料，特别查负号、上下标、积分限、向量、分母括号、单位；英文与中文过程结果一致。
- 浏览器加载真实本地页面，等待本地字体与公式完成；查看解析失败状态和控制台资源错误。至少覆盖长分式、积分/求和、向量、矩阵/分段和本次实际存在的特殊结构。
- 桌面、390px 手机及打印时无缺字/截断；宽公式只在自己的容器内滚动，不把正文撑开。打印过宽式应合理缩放或分页，不能丢弃式子。
- 阻断网络后重新加载验证：CSS、脚本、字体、原公式图片均来自本地；CDN 加载失败不能影响核心学习内容。
- 渲染失败和未确认转录是待修复项。可以交付明确标注的部分资产及缺失清单，不能将其标为完整、已核验成果。
