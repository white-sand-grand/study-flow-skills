# 题型复习：复习稿设计

用户说“题型复习”时必读。以用户提供的《期末计算大题复习稿》的信息组织与视觉为参考，通用实现是 `build_page.py` 的 `kind: review`、`assets/study-review.css` 和 `assets/examples/review.json`。只沉淀设计，不把参考稿的课程、题目、优先级、页数或答案带入新课程；技能在其他目录也须能独立工作。

## 组织与样式

- 炭灰 `#25323a` 的紧凑固定顶栏，显示页名、用户手动勾选的掌握数量和进度条。正文灰白 `#f4f6f7`，白色题型区，青绿 `#087f6a` 用于题型编号、当前目录与结论；蓝色 `#2764aa` 用于公式、方法，琥珀色用于条件提醒，红色用于明确错误。所有颜色含义均有文字说明。
- 桌面约 248px 左目录，正文上限约 1100px；题型区使用 6px 小圆角、细边框、克制阴影、清晰分隔与充足留白。正文系统中文字体 16px、行高约 1.72；不复用原稿的 ASCII 矩阵、未渲染公式或仅以上下标拼装数学式。
- 复习范围与顺序 → 题型/识别线索/方法/来源依据的地图 → 公式或方法速查 → 逐题型代表题 → 答案速查 → 原图与来源核验。材料不足处明确标注，不将“有计算链”自动说成“必考”。只有有证据时才写优先级，并标明老师要求、真题、作业或推测。
- 每个代表题用“题型编号 + 名称 + 来源/范围”开头。桌面左侧是原题文字、解题步骤、具体中文解析、理论依据和易错点，右侧是对应 PDF/PPT 的原题/关键课件裁图及页码说明，比例约 1.15:0.85。手机单列，图文保持对应；长公式和表格只在独立容器滚动，不截断。
- 默认“讲解”模式显示完整过程和答案，提供“只做题”“公式速查”切换以支持自测。只做题隐藏解答，速查显示原题型与公式/方法；导航或搜索跳到被隐藏的内容时恢复讲解，打印恢复完整内容。不要照搬参考稿默认折叠全部正式解答的行为；自测答案仍可折叠。
- “已掌握”仅由用户勾选，本地按课程页面与稳定题目 ID 保存，不能据此声称模型测得了能力或推断用户错题。保留现有可关闭/重开的分层目录、手机目录、全库/本页离线搜索、原图原位返回、自测、打印及总目录入口。

## 原题图、公式与中文解析

1. 对从 PDF/PPT 选出的具体题目，渲染相应原页或幻灯片并裁出完整题干/图表区域，保留条件、子问、图注、答案所需标注与必要上下文；归档到课程库 `sources/`，在本题旁直接展示，不能只给文件名、PDF 链接或不相干示意图。来源写清文件、PDF 物理页/幻灯片号（与印刷页码不同时并列）和题号。跨页题保留多图，不能用整份文档封面代表原题。
2. 有原图时同时提供经核对的文字题干和可搜索公式；原图不是免做公式转录的理由。按 `formula-rendering.md` 用本地 KaTeX 完整渲染原题、解析、速查、表格及答案的全部数学式，包括矩阵、向量、多行推导。确实不支持的原式使用清晰原公式裁图并记录来源。
3. 课件只有知识点而无具体题目时，展示相关课件截图并明确标为“课件知识图”；另编练习须标为“自编练习”，不能称为原题。纯文字输入确无图可说明材料形态；本应有图但未取得时登记待补，不能用 `source_images_note` 把缺失伪装成无图。
4. 中文解析具体、生动，解释识别线索、方法选择、符号意义、关键运算、结果含义及检查，配合本题数值、图上点/箭头或合适类比。所有超出高中知识的部分执行 `content-flow.md` 的完整讲解标准；只有本 HTML 其他题已完整讲过同一原理才允许带锚点简写复用。英文题照常保留完整双语流程。

## 内容规格与构建

先读 `assets/examples/review.json`。沿用作业的 `problems`、`parts`、`answer_html`、`source_images`、`sources_html`，新增：

| 字段 | 用法 |
| --- | --- |
| `kind: review` | 选择题型复习设计；学习索引登记为 `review` |
| `overview_html` | 真实覆盖范围、材料边界与建议顺序 |
| `types_html` | 题型地图，链接到本次具体代表题，说明识别线索、方法及来源依据 |
| `quick_reference_html` | 已渲染公式及适用条件；无公式学科使用理论/方法速查 |
| 每题 `source_image_ids` | 引用 `source_images` 中对应图的 ID，在本题旁显示；同题可多图，多个题可共用一图 |

有来源图的代表题必须填写 `source_image_ids`，每张图的 `label` 说明它是原题还是课件知识图及来源。确无图则提供真实的 `source_images_note`；缺图与未核实知识单独标注为未完成。所有题目保留 `language: zh/en` 及对应完整 `parts`，不因复习模式跳过翻译、英文过程或中文解析。

```text
python <技能目录>/scripts/build_page.py <复习规格.json> --library <现有课程库> --page review-<范围>.html
python <技能目录>/scripts/check_library.py <现有课程库>
```

保持既有学习库位置、入口、离线搜索、索引、增量处理和稳定锚点；更新页先读旧内容，再使用 `--replace`。已有同主题复习页就原位更新，不另造平行学习库。保留规格到课程库 `page-specs/`。

## 验收

- 每个题型有已核实代表题/自编题标记、来源、对应原图、完整语言流程、具体中文解析和结论；原图、重绘、自编练习各自标清。
- 逐题审查所有超出高中范围的知识；简写引用必须在同 HTML 内命中已经完整解释的题目，不能只指到公式表或另一页。
- 除通用结构与公式核验外，检查讲解/只做题/速查、手动进度、目录开关、搜索命中隐藏步骤后的恢复、原图往返和打印展开。桌面、约 390px 手机、打印和离线检查照常执行；工具不可用则报告未核验，不能称全部通过。
